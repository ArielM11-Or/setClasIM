# setClasIM - Organizador de Aula UPDS

Control de clase multidisciplinario con interfaz futurista y herramientas interactivas para gestión docente.

## 🚀 Características

- **Control de Asistencia**: Registro y seguimiento con escáner de códigos QR y generador integrado.
- **Sorteo de Participación**: Selección aleatoria con animaciones y efectos visuales para dinamizar la clase.
- **Creador de Grupos**: Distribución ágil de estudiantes con interacción drag-and-drop.
- **Interfaz Futurista**: Diseño cyberpunk / dark mode con paleta neón, optimizado para proyección o uso directo.

## 💻 Ejecución Local

Puedes abrir directamente el archivo `organizadorinicial.html` en tu navegador, o iniciar un servidor local:

### Con Python:
```bash
python -m http.server 8000
```
Luego ingresa a `http://localhost:8000/organizadorinicial.html`.

### Con Node.js:
```bash
npx serve .
```
